ÉTAPES D'INSTALLATION & DÉMARRAGE
──────────────────────────────────────────────────────────────────────────────

1️⃣ INSTALLER LES DÉPENDANCES
   $ npm install
   
   ✓ React 18.3 + TypeScript
   ✓ React Router v6
   ✓ Tailwind CSS 3.4
   ✓ Recharts 2.12 (graphiques)
   ✓ Lucide React (icônes)
   ✓ Vite 5.4 (build)

2️⃣ DÉMARRER LE SERVEUR DE DÉVELOPPEMENT
   $ npm run dev
   
   → App ouvre automatiquement à http://localhost:5173
   → Hot reload activé

3️⃣ EXPLORER LE PROTOTYPE
   
   Cliquez "Changer de profil" (en haut à droite) pour tester:
   
   ☐ Explorateur (Visiteur) - Accès lecture seule
   ☐ Aventurier Valentin (Joueur) - Accès partiel
   ☐ Maître Élodie (MJ) - Accès complet
   ☐ Éditions D&D Premium (Éditeur) - Dashboard

4️⃣ PAGES À TESTER (ordre recommandé)
   
   → / (Landing)
      Découvrez la promesse produit
      
   → /catalog
      Explorez jeux et livres avec filtres
      Changez de vue: Livres ↔ Jeux
      
   → /book/dnd-players-guide
      Fiche détail livre avec accès verrouillés
      
   → /game/dd5
      Fiche détail jeu avec stats
      
   → /pricing
      Comparez les 3 offres d'abonnement
      
   → /dashboard
      (Sélectionnez profil Éditeur d'abord)
      Dashboard complet avec graphiques
      
   → /library
      (Sélectionnez profil Joueur ou MJ)
      Votre bibliothèque personnelle
      
5️⃣ CONSTRUIRE POUR PRODUCTION
   $ npm run build
   
   → Fichiers de production dans /dist
   → Prêt pour deployment
   → Build verification: npm run preview
