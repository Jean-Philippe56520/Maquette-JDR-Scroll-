# Maquette JDRscroll

Ce dépôt est réservé aux maquettes et prototypes destinés aux échanges avec Kevin. Il est distinct de l'application JDRscroll en production.

## Première maquette
Le projet source React/TypeScript/Vite a été préparé pour être importé ici. **L'import des fichiers applicatifs reste à effectuer** ; le dépôt contient pour l'instant la configuration de déploiement.

## Netlify
Projet réservé : https://app.netlify.com/projects/maquette-jdrscroll

Une fois les sources importées dans la racine du dépôt (dossiers `src/`, `package.json`, `package-lock.json`, `index.html`, etc.), connecter ce dépôt GitHub au projet Netlify, branche `main`.

La configuration `netlify.toml` prévoit la construction Vite et les routes React Router.
